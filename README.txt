# দোতলার বারান্দা — সম্পূর্ণ ফ্রি পারিবারিক ম্যাগাজিন

## চালু করার নিয়ম
1. এই ZIP ফাইল extract করুন।
2. `index.html`-এ ডাবল ক্লিক করুন।
3. অনলাইনে প্রকাশ করতে GitHub Pages ব্যবহার করুন।
4. `index.html`-এর এই অংশটি নিজের Google Form লিংক দিয়ে বদলান:
   `https://forms.google.com/`

## Google Form সংযোগ
Google Form তৈরি করে এর প্রশ্ন রাখুন:
- নাম
- পরিবারের পরিচয়
- বিভাগ
- লেখার শিরোনাম
- সম্পূর্ণ লেখা
- ছবি/ফাইল আপলোড
- প্রকাশের অনুমতি

তারপর `index.html`-এ `https://forms.google.com/` খুঁজে আপনার Form URL বসিয়ে দিন।

## নিজের তথ্য বদলানোর জায়গা
- পরিবারের নাম: `দোতলার বারান্দা`
- সদস্যদের নাম: `index.html`-এর family-grid অংশ
- প্রচ্ছদ: `.cover` অংশ
- লেখা: `article.html`
- ছবি: `gallery.html`
- রঙ ও ডিজাইন: `style.css`

## GitHub Pages
GitHub-এ নতুন repository তৈরি করে সব ফাইল আপলোড করুন:
Settings → Pages → Deploy from branch → main → Save

## গুরুত্বপূর্ণ
এটি একটি সম্পূর্ণ static website। Google Form-এ লেখা জমা হবে, কিন্তু নতুন লেখা স্বয়ংক্রিয়ভাবে সাইটে প্রকাশ হবে না। সম্পাদক হিসেবে অনুমোদিত লেখা `article.html` বা `index.html`-এ যোগ করতে হবে। এটি নিরাপদ ও বিনামূল্যের সহজ পদ্ধতি।
